Data centre design

SD-DC

An agentic stack for designing data centres.

Today a data centre is sized, routed, costed and simulated in a dozen tools that don't talk to each other, and people carry the numbers between them. SD-DC treats each of those steps as a tool call an agent can make: cable sizing, tray and pipe routing, parametric CAD, CFD thermals and a live digital twin. Every result shows its working and gets checked by running it.

Its shared model of the building is IndustroML: one text format for containers, assets, interfaces and connections across electrical, mechanical, data and control.

Computer vision

cvkit

Cameras that tell you about the things that matter.

A multi-camera streaming and AI toolkit. Point it at security cameras and it flags what you care about: a car or person you don't recognise, an animal, smoke. A thin edge agent on the local network does motion detection; heavier vision work runs off the ingest path, and synthetic footage keeps the tests independent of real cameras.

Voice agents

Voxhelm

Talk to your AI agent, out loud.

A voice app for AI agents. Create an agent, give it a face and a voice, then call it and just talk: it answers in real time with a live transcript, and you can switch to text chat when you can't speak. Agents are hosted for you, each in its own container, so there's nothing to install or keep running.

Developer tooling

TeamAICoder

A desktop workbench for running many projects with AI coding agents.

One window per project, organised by stage of the lifecycle: ideas, design, plan, build, test, deploy and operate. Each stage holds tabs that can be files, terminals or embedded web pages, so Claude Code or Codex runs in one tab with the spec beside it and the project board in the next. Open source.
